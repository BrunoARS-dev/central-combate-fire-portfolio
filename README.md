# Central Combate Fire

Base técnica da landing page institucional e comercial da Central Combate
Fire. O projeto utiliza Next.js com App Router, TypeScript, Tailwind CSS,
Lucide React e ESLint.

## Desenvolvimento local

```bash
npm run dev
```

A aplicação estará disponível em `http://localhost:3000`.

## Scripts

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera a versão de produção.
- `npm run start`: inicia a versão de produção gerada.
- `npm run lint`: executa o ESLint.

## Organização

- `src/app`: rotas, layout raiz e estilos globais.
- `src/components/layout`: componentes estruturais compartilhados.
- `src/components/sections`: seções da landing page.
- `src/content`: conteúdo e configurações textuais centralizadas.
- `public/images/marca`: logotipos e elementos de marca preparados para uso.
- `public/images/servicos`: imagens relacionadas aos serviços.
- `public/images/projetos`: registros visuais de projetos.
- `referencias`: arquivos originais fornecidos pela empresa; não devem ser
  alterados.

## Estado atual

A estrutura está pronta para receber o conteúdo e o layout definitivo. Nenhuma
seção comercial da landing page foi implementada nesta etapa.
