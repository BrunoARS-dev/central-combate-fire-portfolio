# Mapa de imagens

## Critérios

- **Selecionada:** copiada para `public/images` e apropriada para uso futuro.
- **Secundária:** registro real, mas depende de contexto, autorização ou uso
  específico.
- **Não recomendada:** baixa nitidez, repetição, composição fraca, conteúdo
  sensível ou inadequação editorial.

Não foram encontradas duplicatas binárias exatas. Existem sequências do mesmo
assunto, ângulos próximos e pares que aparentam documentar antes/depois.
